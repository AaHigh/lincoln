# Rules

Three-tier template for Lincoln Pub comedy nights. Numbers are defaults. They change night to night.

## Timeline defaults

- Host arrival: 7:00–7:30
- First comic: 8:00–8:15
- Door cover begins: 8:15
- Heavy-hitter cutoff: 9:00
- Target close: 10:30 (face-offs only if the room is still full)

## Tier 1 — Room Builder

- Window: 7:00 until roughly 8:00 (or until critical mass)
- Length: hard cap 3 minutes
- Fee: $0 (or $1–5 token)
- Ranking: outside the paid competition
- Tips: pure gratuity to the comic

## Tier 2 — Standard Paid

- Window: 8:15–9:00
- Fee: scales with field size and time
  - 1–2 comics: $10–15
  - 3–5 comics: $20–25
  - 6+: $30
- Set length: 4–6 minutes (shorter if the list is long)
- Operator seed: modest floor ($40–75), announced live
- Ranking: among paid comics only
- Paid places: top 30% or hard cap of top 2–3
- Split: proportional to tips received among the paid places, with guaranteed minimum from the seed
- Outside paid places: tips only

## Tier 3 — Heavy Hitter

- Window: 9:00–10:15
- Fee: higher and less elastic ($40–75 or more if a known name is already in)
- Set length: 7–10 minutes (longer if the field is small)
- Operator seed: larger floor ($100–150)
- Same ranking and split rules as Tier 2
- Purpose: keep the room past 9:30 and justify the cover

## Close

Last comic off by 10:15–10:20. Optional short face-off only if the room is still loud. Never extend into a dead room.

## Variables that can change

- Exact start and end of each tier
- Fee amounts and scaling curve
- Seed amounts
- Number of paid places
- Set lengths
- Door cover start time
